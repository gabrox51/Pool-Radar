# Pool Radar

Painel de pools de liquidez em dezenas de redes e DEXes, com APY, TVL, volume e histórico de APY (7D, 30D, 90D e todo o período).

Os dados vêm ao vivo da API pública da [DefiLlama](https://defillama.com/yields):

- `https://yields.llama.fi/pools` para a lista de pools
- `https://yields.llama.fi/chart/{pool}` para o histórico de cada pool

O site é um único arquivo (`index.html`), sem build. Para publicar, basta ativar o GitHub Pages na branch `main`.

Não é recomendação financeira. Cripto é volátil e você pode perder tudo.
